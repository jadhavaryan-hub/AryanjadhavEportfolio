## 1. Purpose of the Portfolio
This portfolio serves as a verified academic and professional showcase developed under the *AI-Assisted Development of a Professional E-Portfolio* coursework. It highlights core competencies in Geographic Information Systems (GIS), satellite Remote Sensing, spatial scripting, and ongoing subject reflections.

## 2. Technologies Used
- **Structure:** Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **Styling:** Modern Vanilla CSS3 utilizing custom property tokens, glassmorphism (`backdrop-filter: blur()`), and responsive CSS Grid/Flexbox layouts.
- **Interactivity:** Vanilla JavaScript for accessible mobile navigation toggling, keyboard navigation, and scroll spy active link updates.
- **Hosting:** GitHub Pages (Static site deployment).

## 3. Principal Sections & Navigation
- **Home:** Academic identity, tagline, quick highlights bar, and featured Earth observation focus.
- **About Me:** 100–150 word introduction covering academic background, specialization, and career goals.
- **Education:** Timeline of degrees, institutions, and core study areas.
- **Technical Skills:** Grouped strictly into 4 domains:
  1. *Geographic Information Systems (GIS)*
  2. *Remote Sensing & Earth Observation*
  3. *Programming & Automation*
  4. *Data & Spatial Visualization*
- **Projects:** Evidence-backed research projects documenting problem statements, study areas, datasets, tools, and outputs.
- **Subject Reflections:** Top-level navigation to `reflections/index.html` and individual course pages featuring separate `#theory` and `#practical` reflective analyses (200–300 words each).
- **Resume & Contact:** Public-safe academic CV download and direct email/social links.

## 4. How to Open Locally
1. Clone or download this repository:
   ```bash
   git clone https://github.com/[YOUR-USERNAME]/student-portfolio.git
   cd student-portfolio
   ```
2. Open `index.html` in any modern web browser, or launch using a local development server:
   - Using VS Code: Right-click `index.html` > *Open with Live Server*
   - Using Python: `python -m http.server 3000`
   - Open browser at `http://localhost:3000`
